# Expense Tracker

A beginner-friendly expense tracker web application built using HTML, CSS, and JavaScript.

## Description

This project allows users to add and manage their daily expenses. It dynamically calculates the total amount spent and displays the expense information on the webpage.

## Features

- Add expenses
- Display expense details
- Calculate total expenses
- Delete expenses
- Dynamic updates using JavaScript
- Simple and responsive user interface
- Cherry-colored background design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Array Methods
- Event Listeners
